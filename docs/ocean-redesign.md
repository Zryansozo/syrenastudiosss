
# Syrena: a new creative current

The ocean theme remains the core visual identity. The Home flip postcard and the Services ocean renderer, marine objects, and six reveal films are retained. The rest of the site uses a continuous soft-cobalt / warm-paper canvas, sea-glass accents, tidal linework, shell motifs, and labelled studio concepts.

## Content and interactions

- Home: ocean introduction, postcard, shell sculpture, capabilities, interactive palette study, fictional packaging concept.
- Studio: present-tense introduction, creative workbench, values, process; no abrupt dark section.
- Services: preserved interactive ocean, accessible service details, project compass, proposed process.
- Playground: filterable concept studies and native-dialog previews. No client or performance claims.
- Contact: native form validation, local brief preview, email draft, copy, and text download. No submission backend or false sent confirmation.
- FAQ: searchable answers, category filters, native expandable answers, empty state.
- Shared: responsive navigation with native mobile dialog, skip link, calmer footer and factual site notes.

The existing contact address is hello@syrena.agency. Confirm ownership and delivery before a public launch. No invented phone number, offices, founding year, client statistics, legal registration, or SLA remains in the active pages.
