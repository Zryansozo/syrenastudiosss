# SyrenaStudio Ocean Scrapbook Asset Pack

This pack contains isolated transparent PNG assets plus the wide background reference.

## Intended use
Build a layered, interactive 3D website background:
- far layer: paper scraps / torn paper / grid
- mid layer: doodles / postage / bubbles / postcards
- foreground: shells / starfish / seahorse / jellyfish / coral / fish
- subtle mouse parallax
- independent floating/drifting motion
- gentle rotation and depth scaling
- occasional slow swimming/floating paths for marine elements

## Visual direction
SOUR-style chaotic scrapbook collage translated into SyrenaStudio's navy/blue/cream ocean identity.

## Important
Keep the six service cards as the visual focal point. Do not let animated assets cover their text.
